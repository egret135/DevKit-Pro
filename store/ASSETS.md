# Chrome Web Store 上架图片清单

上传位置：Chrome Web Store Developer Dashboard → 商品 → 商店宣传资料。

## 已就绪（仓库内）

| 资源 | 路径 | 尺寸 | Dashboard 字段 |
|------|------|------|----------------|
| 扩展图标 | `icons/icon128.png` | 128×128 | 随 ZIP 打包；也可作商店图标 |
| 小宣传图 | `store/assets/promo-small-440x280.png` | 440×280 | Promotional images → Small（**必填**） |

## 需你本机补齐（截图）

官方要求至少 **1** 张截图；建议 **3** 张，1280×800（或 640×400），直角、无边框留白。

| # | 场景 | 建议内容 | 状态 |
|---|------|----------|------|
| 1 | 转换器 | DDL → Go Struct 双栏结果 | 待截取 |
| 2 | Markdown | 预览含表格 / 公式或 Mermaid | 待截取 |
| 3 | 工具箱或媒体 | 时间戳、JSON 或媒体信息任一代表性界面 | 待截取 |

截取步骤：

1. `chrome://extensions` → 加载已解压扩展 → 打开工作台全屏  
2. 切到对应模块，系统截图或 Chrome 窗口截图  
3. 若分辨率不是 1280×800，用预览 / 图像工具裁切到该尺寸后再上传  
4. 勿包含个人 Token、真实密码、隐私文件路径  

## 可选

| 资源 | 尺寸 | 说明 |
|------|------|------|
| Marquee 宣传图 | 1400×560 | 非必填；有助于商店推荐位 |

完成后在 Dashboard 勾选确认：小宣传图已上传、截图 ≥1、隐私政策 URL 可打开。
