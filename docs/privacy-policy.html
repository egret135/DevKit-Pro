English

Overview

DevKit Pro is a single offline developer workbench that runs entirely in your browser. It does not operate a backend server for processing your content, and it does not sell or share your data with advertisers.

Data we store locally

The extension may store the following on your device only. Tool inputs (DDL, JSON, Markdown, images, audio, video, passwords, tokens, etc.) are processed in memory for the active session and are not uploaded to our servers.

DataPurposeStorage
UI and tool preferences (theme, font, indent, panel options, converter/generator options, media track filters, and similar settings)Remember workbench configuration across sessionschrome.storage.local and/or chrome.storage.sync, with localStorage as fallback
Draft Markdown textRestore unfinished document inputlocalStorage

If Chrome Sync is enabled for extensions, preference data in chrome.storage.sync may sync across your signed-in Chrome browsers via Google’s sync infrastructure. We do not operate that sync service. You can clear stored data by clearing the extension’s site data, uninstalling the extension, or using in-app clear actions.

Data we do not collect

  • We do not upload your DDL, JSON, Markdown, images, audio, video, passwords, tokens, or other tool inputs to our servers.
  • Generated passwords and media files are handled in memory (or saved only when you explicitly download/export to your computer).
  • We do not use analytics SDKs, advertising trackers, or third-party tracking pixels.
  • We do not require an account for the extension itself.

Formatting, conversion, preview, export, hashing, and media helpers happen locally in the browser.

Permissions

PermissionWhy
storageSave preferences and options on your device
downloadsSave exported files when you choose to download

Copy uses the browser clipboard API only when you click Copy. The extension does not request the clipboardWrite permission. It does not read browsing history or arbitrary websites. Optional map links in EXIF results open OpenStreetMap in a normal browser tab when you click them; no location data is sent to us.

Third-party libraries

Bundled libraries (CodeMirror, Marked, Mermaid, KaTeX, MediaInfo WASM, and others) run locally inside the extension and are not used to send your content elsewhere.

Children

DevKit Pro is intended for developers and is not directed at children under 13.

Changes

We may update this policy when features or permissions change. The date above will be revised. Continued use means you accept the updated policy.

中文

概述

DevKit Pro 是一款在浏览器本地运行的单一用途开发者工作台扩展。我们没有用于处理你内容的后台服务器，也不会向广告商出售或共享你的数据。

本地存储

扩展可能仅在你的设备上保存下列数据。工具输入（DDL、JSON、Markdown、图片、音视频、密码、Token 等）在会话中于内存处理，不会上传到我们的服务器。

数据用途位置
界面与工具偏好（主题、字体、缩进、面板选项、转换器/生成器选项、媒体轨筛选等）记住工作台配置chrome.storage.local 和/或 chrome.storage.sync，必要时回退 localStorage
Markdown 草稿恢复未完成输入localStorage

若你启用了 Chrome 扩展同步，chrome.storage.sync 中的偏好可能经由 Google 的同步机制在你登录的浏览器之间同步；该服务不由我们运营。可通过清除扩展站点数据、卸载扩展或应用内清除操作删除本地数据。

我们不收集的内容

  • 不会上传 DDL、JSON、Markdown、图片、音视频、密码或 Token。
  • 生成的密码与媒体文件仅在内存中处理（或在你主动导出时保存到本机）。
  • 不使用分析或广告追踪。
  • 扩展本身不需要注册账号。

权限

权限用途
storage在本地保存偏好与选项
downloads在你选择导出时保存文件到本机

复制仅在你点击「复制」时通过浏览器剪贴板完成。扩展不申请 clipboardWrite，也不读取浏览历史或任意网站。EXIF 结果中的地图链接仅在你点击时于普通标签页打开 OpenStreetMap，不会向我们发送位置数据。

第三方库

打包的开源库均在扩展内本地运行，不会回传你的内容。

儿童与变更

本产品面向开发者，不针对 13 岁以下儿童。政策变更时会修订文首日期。
